# 经管期末刷题系统

北航经济管理概论期末复习刷题系统，涵盖往届试题的填空、单选、多选、判断、计算等题型。

## 功能

- 📊 **学习仪表盘** — 总题量、正确率、收藏/错题统计
- 📝 **逐题刷题** — 卡片式答题，支持键盘左右键翻页
- 🔍 **筛选** — 按年份、题型、关键字筛选
- ⭐ **收藏夹** — 标记重点题目
- ❌ **错题库** — 自动收录错题，支持重练
- 📋 **列表视图** — 快速浏览所有题目

## 运行方式

### 方式一：直接打开

双击 `index.html` 即可在浏览器中使用。

### 方式二：本地服务器（推荐）

```powershell
# PowerShell
cd 经管
powershell -ExecutionPolicy Bypass -File server.ps1
# 访问 http://localhost:8090/
```

或者用 Python：

```bash
cd 经管
python -m http.server 8090
# 访问 http://localhost:8090/
```

## 目录结构

```
经管/
```

## 技术栈

- 纯前端实现，无需后端
- Tailwind CSS + 原生 JavaScript
- KaTeX 数学公式渲染
- localStorage 持久化答题记录
