# 经管期末刷题系统

北航经济管理概论期末复习刷题系统，涵盖往届试题的填空、单选、多选、判断、计算等题型。

## 功能

- 📊 **学习仪表盘** — 总题量、正确率、收藏/错题统计
- 📝 **逐题刷题** — 卡片式答题，支持键盘快捷键
- 🔍 **筛选** — 按年份、题型、关键字筛选
- ⭐ **收藏夹** — 标记重点题目
- ❌ **错题库** — 自动收录错题，支持重练
- 📋 **列表视图** — 快速浏览所有题目
- 📥 **试卷详情** — 查看试卷信息、做题进度、下载原始文件
- 💾 **数据管理** — 导入/导出答题记录（JSON / Markdown）

## 键盘快捷键

### 全局快捷键

| 按键 | 功能 |
|------|------|
| `Tab` | 切换答题 / 列表视图 |
| `Esc` | 退出输入框 / 关闭试卷详情弹窗 |
| `L` | 跳转到收藏夹 |
| `W` | 跳转到错题库 |
| `M` | 跳转到数据管理 |
| `I` | 打开当前题目对应的试卷详情弹窗 |

### 答题模式

| 按键 | 功能 |
|------|------|
| `←` / `→` | 上一题 / 下一题 |
| `↑` / `↓` | 上一行 / 下一行（导航网格中上下跳转，跳 4 题） |
| `A` - `F` | 选择对应选项（单选/多选/判断题，再次按下取消选择） |
| `Enter` | 提交答案（已选好选项或填完答案后） |
| `Shift` | 直接看答案 |
| `1` | 重做此题（已提交答案后） |
| `2` | 收藏 / 取消收藏（已提交答案后） |
| `3` | 加入错题 / 移出错题（已提交答案后） |
| `4` | 下一题（已提交答案后） |

### 列表模式

| 按键 | 功能 |
|------|------|
| `↑` / `↓` / `←` / `→` | 选中上一行 / 下一行 |
| `Enter` | 跳转到选中题目的详情答题页 |

> 💡 **输入框提示**：光标在输入框内时，A-F 键和 4 键不会触发快捷操作；按 `Esc` 可退出输入框，`Enter` 仍可提交答案。

## 运行方式

### 方式一：直接打开

双击 `index.html` 即可在浏览器中使用。

### 方式二：本地服务器（推荐）

```powershell
# PowerShell
cd 经管
powershell -ExecutionPolicy Bypass -File server.ps1
# 访问 http://localhost:8090/
```

或者用 Python：

```bash
cd 经管
python -m http.server 8090
# 访问 http://localhost:8090/
```
